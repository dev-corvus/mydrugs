# ![MyDrugs logo](./assets/icons/mydrugs-favicon.ico) MyDrugs Web Project

A front-end recreation inspired by the fictitious online marketplace featured in the Netflix series **"How to Sell Drugs Online (Fast)"**.

[Live Demo](https://dev-corvus.github.io/mydrugs/) • [Repository](https://github.com/dev-corvus/mydrugs)


## ꩜ About the Project

This project is an educational front-end development exercise created as part of the **Transforme-se** program — a partnership between **Serasa Experian** and **Instituto PROA**.

* **Course:** Transforme-se (Instituto PROA & Serasa Experian)
* **Class:** Turma 23
* **Instructor:** Prof. Mago da Silva

The core objective was to practice and solidify fundamental concepts of **HTML5** and **CSS3**, focusing on semantic markup, modern layout techniques, responsive design, and themed styling based on real pop-culture design references.

> ⚠️ **Disclaimer:** This website is purely fictional, educational, and inspired by the narrative of the Netflix show *"How to Sell Drugs Online (Fast)"*. It does not promote, sell, or endorse any illicit substances or activities.

## ꩜ Built With

* **HTML5:** Semantic document structuring (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<ul>`, `<form>`).
* **CSS3:** Custom properties (CSS Variables), Flexbox, CSS Grid, media queries, and blend-mode styling.
* **Typography:** Clean geometric sans-serif fallbacks inspired by the brand wordmark.

## ꩜ Key Learning Objectives & Features

- [x] **CSS Layouts:** Mastering Flexbox for navigation, card grids, and input alignment.
- [x] **Form Controls:** Semantic forms, customized inputs, textareas, and grouped checkbox layouts.
- [x] **Responsive Adaptation:** Fluid layouts adaptable to standard viewport widths.
- [x] **Version Control:** Practicing Git/GitHub workflow and GitHub Pages deployment.
- [x] **Color Palette & Theme:** Consistent dark-mode theme utilizing CSS variables (`:root`).

## ꩜ How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/dev-corvus/mydrugs.git
   ```

2. Navigate into the project folder:
   ```bash
   cd mydrugs
   ```

3. Open `index.html` in your favorite browser or use the **Live Server** extension in VS Code.
